공통 등장 금지 목록

  • 엄청 쉬움 모드를 소지해도 이 제거 목록의 적용을 면제하지 않습니다. 체력 제한 완화와는 별도 규칙입니다.

  • 장신구 제거는 일반·황금·흡수 상태의 소지 여부를 확인해 제거를 시도합니다. 아이템은 같은 종류의 모든 복사본을 제거합니다.

누적 밴의 수집과 초기화

퀄리티 3·4 아이템을 얻으면 다음 새 게임의 밴 후보로 기록합니다. 한 런에서 같은 종류를 여러 번 획득해도 후보에는 한 번만 기록하며, 이전 밴을 유지한 채 새 후보를 최대 10개 추가합니다.

  • 게임 시작 첫 프레임의 초기 소지품은 후보 수집에서 제외합니다. 이후 얻는 시작방 보상은 기록될 수 있습니다.
  • 이미 밴된 항목, 아빠의 쪽지와 퀘스트 태그가 붙은 아이템은 추가 추첨에서 제외합니다. 제외 후 후보가 10개보다 적으면 남은 후보만 추가합니다.
  • 이어하기는 새 추첨을 하지 않고 현재 밴을 유지합니다.
  • 밴 해제 거지는 현재 밴이 있고 해제가 예약되지 않았을 때 시작방에 등장합니다. 허쉬 구간의 시작방에는 등장하지 않습니다. 거지에게 접촉해 확인 문구를 읽고, 떨어졌다가 다시 접촉하면 초기화를 예약합니다.
  • 밴 해제 예약이나 모드 아이템 삼사라를 획득한 상태에서 다음 새 게임을 시작하면 누적 밴을 비우고 그 게임의 추가 추첨을 건너뜁니다. 공통 금지와 캐릭터별 금지는 그대로 적용합니다.

선택 묶음과 등장 퀄리티

특정 방에 처음 들어갈 때 바닥에 놓인 아이템을 하나의 선택 묶음으로 바꿉니다. 묶음에서 하나를 획득하면 나머지는 사라집니다. 아이템을 다시 뽑는 과정에는 방 종류와 층에 따른 퀄리티 제한도 적용합니다.

  • 선택 묶음 대상은 미니보스방, 블랙마켓, 울트라 비밀방, 악마방, 천체관, 도전방, 보물방, 주사위방, 비밀방, 일급비밀방, 저주방입니다. 처음 입장해 생성된 받침대에 적용합니다.
  • 주사위방에는 열쇠 거지 배열의 추가 아이템 2개를 같은 선택 묶음으로 생성합니다.
  • 대체 루트 첫 보물방에는 일반 첫 보물방의 퀄리티 0·1 재추첨을 적용하지 않습니다. 첫 층 악마방·비밀방의 퀄리티 4 재추첨은 루트 형태를 구분하지 않습니다.

기계의 비용과 작동

기계의 종류에 따라 아이템 전환 방식과 비용이 다릅니다. 초반 보스 보상의 세미 글리치 머신 외에도 기존 슬롯머신과 크레인 게임을 모드 기계로 교체합니다.

  • 기존 슬롯머신은 대결 모드에서 글리치 머신으로 교체합니다.
  • 일반 루트 첫 두 층의 보스방에 있는 기본 재입고 기계는 세미 글리치 머신으로 교체합니다. 대체 루트에는 이 교체를 적용하지 않지만 보스 클리어 보상의 세미 글리치 머신은 별도로 등장합니다.
  • Caves I에 대응하는 구간까지 상점에 처음 들어가면 기본 재입고 기계 1개를 추가 생성합니다. 기본 재입고 기계와 커스텀 재입고 기계의 작동 규칙은 다릅니다.
  • 기존 크레인 게임은 아스트로 크레인 게임으로 교체하며, 표시 보상과 4가지 가격을 생성할 때 결정합니다. 모드의 카인 생득권 효과가 있으면 정해진 확률로 비용을 소비하지 않습니다.

  • 클리어되지 않은 지정 보스방에서 패널티 피격을 받으면 일반 Death’s Head 2마리를 확정 생성합니다. 대상은 엄마 발, 허쉬 구간, Sheol·Cathedral 구간, Chest·Dark Room·메가 사탄 구간, 보이드 구간, 마더와 비스트방입니다.
